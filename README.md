# Laundry Valet Service

สไลด์นำเสนอบริการรับฝากซัก-อบ-พับสำหรับร้านนิติ รีดเรียบ

## เปิดดูหน้าเว็บ

เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือเผยแพร่ repo นี้ด้วย GitHub Pages หน้าแรกจะเปิดจาก `index.html` โดยอัตโนมัติ ไฟล์ `laundry-valet-deck.html` จะพาไปยังหน้าแรกเพื่อรองรับลิงก์เดิม

## การควบคุมสไลด์

- กดปุ่ม **ก่อนหน้า / ถัดไป** บนหน้าจอ
- ใช้ปุ่มลูกศร `←` `→` หรือ `↑` `↓` บนคีย์บอร์ด
- กด `Home` เพื่อกลับสไลด์แรก และ `End` เพื่อไปสไลด์สุดท้าย
- บนมือถือ เลื่อนเนื้อหาในแต่ละสไลด์ได้ และใช้ปุ่มด้านล่างเพื่อเปลี่ยนสไลด์

## เผยแพร่ด้วย GitHub Pages

ใน GitHub ไปที่ **Settings → Pages** แล้วเลือก **Deploy from a branch**, branch `main`, folder `/(root)` จากนั้นบันทึก หน้าเว็บจะเผยแพร่จากไฟล์ `index.html` ที่ root ของ repo
